# 商品卖点提炼方法

## FAB 法则

- **F（Feature）**：商品特性/功能 —— 这是什么
- **A（Advantage）**：这个特性的优势 —— 为什么好
- **B（Benefit）**：对用户的好处 —— 对我有什么用

### 示例

- Feature：蓝牙 5.3 芯片
- Advantage：连接更稳定、延迟更低、功耗更小
- Benefit：追剧音画同步、打游戏不延迟、充电一次用一周

## 卖点排序原则

1.  **用户相关性**：对目标用户最重要的卖点排前面
2.  **差异化**：竞品没有或不如的优势优先突出
3.  **可感知**：用户能直接感受到的好处 > 技术参数
4.  **场景化**：在具体场景下才能体现的卖点

## 常见卖点提炼角度

### 功能角度
- 解决了什么问题（降噪解决噪音干扰）
- 提升了什么体验（长续航减少充电焦虑）

### 情感角度
- 满足了什么心理（性价比高 → 买得值）
- 带来了什么感受（音质好 → 沉浸感）

### 社交角度
- 代表了什么身份（学生党高性价比选择）
- 分享创造了什么话题（宿舍好物推荐）

## 用户痛点与卖点的对应

| 用户痛点 | 对应卖点 |
|---------|---------|
| 环境嘈杂无法专注 | 主动降噪功能 |
| 经常忘记充电 | 超长续航 |
| 预算有限 | 高性价比价格 |
| 佩戴时间长不舒服 | 人体工学设计 |
| 选择困难不知道买哪个 | 销量/口碑背书 |

## 提炼步骤

1.  **列出所有商品特性**：把能想到的特色全部写出来
2.  **筛选有效卖点**：去掉对目标用户没有吸引力的
3.  **转化为用户利益**：每个特性都要说清楚对用户的好处
4.  **排序优先级**：按对目标用户的重要性排序
5.  **场景化包装**：把卖点放到具体使用场景中描述
