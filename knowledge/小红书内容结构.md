# 小红书内容结构

## 种草笔记核心公式

**痛点引入 + 产品出现 + 体验描述 + 效果展示 + 推荐总结**

## 标题策略

1.  **场景痛点型**："每天在图书馆学习，被周围声音影响真的很崩溃……"
2.  **对比反差型**："从几十块到几百块，我都试过了……"
3.  **数字具体型**："用了 30 天的真实感受"
4.  **解决方案型**："学生党必看！解决宿舍学习噪音的 3 个方法"
5.  **情绪共鸣型**："真的会谢！才发现降噪耳机这么好用"

## 正文结构

### 开头（痛点引入）
- 第一人称，真实场景
- 描述具体困扰或需求
- 让读者产生共鸣

### 中间（产品体验）
- 怎么发现这个产品的（来源可信）
- 使用过程中的感受
- 具体细节描述（外观、手感、音质、续航等）
- 对比其他产品的真实体验

### 结尾（推荐总结）
- 使用前后对比
- 适合什么人群
- 购买建议（什么配置性价比高）
- 互动引导（问大家有没有同感）

## 内容风格要点

1.  **真实感**：像朋友在分享，不是什么官方广告
2.  **细节**：具体的使用场景和体验细节，不是空洞的好用
3.  **适度的缺点**：适当说一两个小缺点，增加可信度
4.  **视觉感**：描述带有画面感，让读者身临其境
5.  **口语化**：像在和朋友聊天，不要书面腔

## 标签策略

- 主标签（品类）：#降噪耳机 #蓝牙耳机
- 场景标签：#宿舍好物 #学习必备
- 人群标签：#学生党 #考研党
- 情感标签：#好物分享 #真实推荐
- 数量：5-8 个标签为宜

## 注意事项

1.  不要写成硬广，小红书用户对广告敏感
2.  不要只说"很好用"，要说"好用在什么地方"
3.  图片比文字重要，但这里只聚焦文字内容
4.  互动率（点赞评论）比阅读量更重要
