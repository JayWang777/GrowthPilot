# 商品摄影规范与 AI 绘图 Prompt 标准

## 一、电商主图设计原则

### 1.1 构图规范
- 商品在画面中占比 80%-90%
- 居中构图为主(商品置于画面中轴线)
- 可用三分法做场景图(商品放在交叉点上)
- 留白比例控制在 10%-15%,避免画面过密

### 1.2 光线要求
- 主光源 45°角打光,展现商品立体感
- 辅光填充阴影,亮度为主光的 50%
- 避免过曝或欠曝
- 金属/镜面材质需要柔光箱消除反光

### 1.3 背景选择
- 白底图(纯白 #FFFFFF 或非常浅的灰 #F5F5F5)
- 场景图使用与商品色调互补的柔和背景
- 小红书风格避免纯白背图,使用生活场景背景
- 深色商品建议浅色背景,浅色商品可用中度背景

### 1.4 分辨率
- 主图最小 800×800px,推荐 1600×1600px
- 详页图宽度 750-1200px
- 小红书竖图 1080×1350px(3:4 比例)

---

## 二、详情页图片结构

电商详情页建议 5-8 张图片,按以下顺序:

1. **首图(主图)**: 白底/纯色底纯商品展示,突出外观设计
2. **卖点图**: 2-3 张,每张突出一个核心卖点(材质/工艺/设计)
3. **细节图**: 特写展示关键部位(接口/缝线/Logo/质纹)
4. **场景图**: 商品在实际使用场景中的展示
5. **规格图**: 尺寸对比、颜色选择等规格信息
6. **对比图**: 与竞品或解决的痛点的对比
7. **保障图**: 售后保障、品质承诺(可选)

## 三、小红书视觉风格

### 3.1 色调偏好
- 暖色调为主(奶油色/杏色/淡粉色/浅驼色)
- 莫兰迪色系(饱和度低 30%-40%)
- 避免高饱和荧光色
- 加轻微颗粒感滤镜提升真实感

### 3.2 场景特点
- 自然光拍摄感(窗边/午后阳光/柔和光影)
- 生活化场景(书桌/沙发/床头/咖啡角/阳台)
- 有"人的痕迹"但不露全脸(手部出镜/侧面剪影)
- 道具点缀但不喧宾夺主(咖啡/绿植/杂志/布料)

### 3.3 构图风格
- 俯拍(flat lay)适合多件物品
- 45°角适合单件商品
- 大光圈浅景深突出主体
- 留白较多,画面透气感

## 四、AI 绘图 Prompt 构造规范

### 4.1 正向 Prompt 结构

```
[主体描述] + [材质/风格] + [场景/背景] + [光线/氛围] + [画质标签]

主体描述: 精确描述商品外观、颜色、形态
材质/风格: 指定材质质感和视觉风格
场景/背景: 描述环境背景(纯白/场景/工作室)
光线/氛围: 自然光/柔光/暖光/摄影棚灯光
画质标签: 8k, ultra detailed, product photography, commercial photography, studio lighting
```

### 4.2 Negative Prompt 模板

```
blurry, low quality, distorted, warped, deformed, watermark, text overlay, logo corruption, different color from reference, different shape from reference, cluttered background, harsh shadows, overexposed, underexposed, noisy, grainy, color shift, product damage, bad anatomy, extra limbs, missing parts
```

### 4.3 各场景 Prompt 示例

**商品主图**:
```
正面: {product_name}, white background, commercial product photography, studio lighting, 8k, ultra detailed, centered composition, clean minimalist, e-commerce photography
负面: shadow on product, reflection, uneven lighting, background gradient, watermark
```

**材质细节图**:
```
正面: {material} texture close-up of {product_name}, macro photography, ultra detailed, shallow depth of field, studio lighting, showing fine craftsmanship
负面: blurry texture, out of focus, color inaccurate, deformed material
```

**使用场景图**:
```
正面: {product_name} in use at {scene}, natural lighting, lifestyle photography, warm atmosphere, candid shot, soft shadows, photorealistic
负面: artificial lighting, posed/unnatural look, messy background, different room style
```

**小红书种草图**:
```
正面: flat lay photography of {product_name} on {surface} with {props}, warm afternoon sunlight, morandi color palette, slight film grain, soft bokeh, cozy aesthetic, lifestyle mood
负面: commercial/studio look, harsh lighting, pure white background, over-saturated colors, unnatural arrangement
```

## 五、商品一致性约束(Product Consistency)

### 5.1 禁止改变的内容
使用 AI 生成商品图片时,必须严格遵守:

- **外观**: 商品形状、结构、比例必须与参考图一致
- **颜色**: 色相、饱和度、明度不得偏移
- **Logo**: 品牌标志样式、位置、大小不得变化
- **材质**: 材质纹理、光泽度、透感必须还原
- **文字**: 包装文字内容、字体、排版必须一致

### 5.2 Consistency Prompt 片段

每条 AI 生图 Prompt 末尾必须追加:
```
(product identity preserved: exact same color, shape, material, and logo as the reference image, no alteration to product appearance)
```

### 5.3 一致性验证要点
- 生成后对比原图确认颜色是否匹配
- Logo 放大检查是否扭曲
- 材质光影方向是否一致
- 商品比例是否变形
