# 抖音短视频运营策略

## 抖音推荐算法核心逻辑

### 流量池递进机制
- 初始流量：200-500 播放（通过标签匹配推送）
- 第一轮筛选：完播率 + 点赞率 → 进入 2000-5000 流量池
- 第二轮筛选：互动率（评论、转发）→ 进入 1w-10w 流量池
- 爆款门槛：综合互动率 > 10% 才有可能进入百万级流量池

### 核心权重指标（从高到低）
1. **完播率**：视频完整播放的比例，影响最大
2. **点赞率**：点赞数 / 播放量，> 3% 算合格
3. **评论率**：评论数 / 播放量，> 1% 算合格
4. **转发率**：转发数 / 播放量，> 0.5% 算合格
5. **关注率**：因该视频关注账号的比例

## 电商推广类视频内容结构

### 前 3 秒（抓住注意力）
- 直接抛出痛点："你是不是也遇到过……"
- 制造反差："99% 的人都不知道……"
- 视觉冲击：产品特写、使用前后对比
- **前 3 秒流失率超过 60%，这是最重要的部分**

### 3-15 秒（核心展示）
- 产品核心卖点，1-2 个就够了，不要贪多
- 展示使用场景，让用户想象自己也在用
- 语言口语化，用"你"开头直接对话用户

### 15-30 秒（信任建立）
- 使用感受、效果展示
- 和同类产品的差异在哪里
- 价格优势或附加价值

### 结尾（转化引导）
- 引导点击购物车/小黄车
- 限时优惠、限量等营造紧迫感
- 引导评论互动

## 不同品类短视频策略

| 品类 | 内容方向 | 前 3 秒钩子 |
|------|---------|------------|
| 3C 数码 | 功能展示、开箱测评 | "这个价格能买到这种配置？" |
| 美妆护肤 | 效果对比、教程 | "用了 7 天，皮肤真的变了……" |
| 家居日用 | 场景痛点、收纳整理 | "租房党一定要看的……" |
| 食品饮料 | 开箱试吃、制作过程 | "停不下来的那种好吃……" |

## Dou+ 投放策略

- 测素材阶段：投 100 元看 3 项数据（完播率 > 30%、互动率 > 5%、转化成本合理）
- 数据好的视频再追投 300-500 元
- 投放定向：优先选"相似达人粉丝"，其次是"兴趣标签"
- 不要投已经自然流量跑不动的视频

## 商品在抖音的展示形式

1. **短视频 + 小黄车**：最主流形式，通过内容种草直接转化
2. **直播带货**：实时互动，转化率最高
3. **商品卡**：搜索流量，标题优化同样重要
4. **达人合作**：通过达人内容触达精准人群
